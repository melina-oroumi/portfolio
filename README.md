# My Portfolio

A lightweight, responsive portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content, navigation, projects, and links.
- `style.css` — layout, typography, colors, and mobile responsiveness.
- `script.js` — automatically updates the footer year.

## Notes
- No JavaScript framework or npm dependencies are needed.
- The design uses Google Fonts; if unavailable, system fonts will be used.
